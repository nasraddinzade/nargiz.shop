# Nargiz Shop — отчёт по прототипу

Демо-прототип для показа владельцу. Next.js 15 (App Router), TypeScript, Tailwind 4, без бэкенда. Товары в `src/data/products.ts`, корзина и выбранный филиал в localStorage.

## Фотографии

**Нашлось и прошло проверку: 96 из 101.**

| Источник | Снимков |
|---|---|
| Birmarket, JSON-LD `image` страницы `birmarket.az/product/{id}` | 96 |
| Сайты брендов | 0 (поиск по 4 позициям без чистого кадра на Birmarket ничего не дал: официальных страниц не нашлось) |
| Другие открытые источники | 0 |

Источник каждой картинки — `public/products/sources.json` (страница, URL исходника, путь к файлу или причина отказа).

Обработка: обрезка белых полей, квадрат 800×800, белый фон, webp. Каждый файл проверен скриптом: открывается как изображение, формат webp 800×800, больше 5 КБ, не одноцветный (стандартное отклонение по каналам > 8). Все 96 прошли. Каждый снимок дополнительно просмотрен глазами на контактных листах — на страницы ошибок, логотипы и баннеры.

**Отбраковано из-за водяных знаков: 0.** Ни на одном снимке водяного знака не найдено.

## Нормализация названий

Кириллических букв внутри латинских слов в данных из MD **не найдено** — примеры «Сollagen», «Кirşan» в срезе уже записаны латиницей. Скрипт генерации всё равно прогоняет замену похожих кириллических букв на латиницу.

Опечатки оставлены как есть (на поиск не влияют): Niacimamide (1082844).

Расхождения со страницами Birmarket (данные не правил, взял из MD):
- 61650: в MD «Medi-Peel Hyal Kombucha Tea-Tox Cream», а адрес страницы на Birmarket — `...azulene-water-calming-mask...`. Фото с карточки — Hyal Kombucha, совпадает с MD.
- 92272: в MD артикул PT465-005, в адресе страницы pt464-005.
- 1101306: в MD «Espresso», в адресе страницы «chocolate».
- 93453: в MD 1.14 q, в адресе страницы 0.04 q.
- 989244: на Birmarket в названии добавлено «Green 5.6 ml», в MD объёма нет.
- 1789210, 2804539, 2886007 и др.: в адресах страниц другие формулировки, сами названия в JSON-LD совпадают с MD.

## Что не подтвердилось / осталось как в приложении

- Часы работы не выводятся (источники расходятся).
- Адрес Nizami не выводится (`addressConfirmed: false`, `SHOW_UNCONFIRMED = false`); кнопка «Xəritədə aç» ищет в 2GIS «Nargiz Shop Nizami».
- Скидки Matsu — по листингу Birmarket (10%), а не по акции из Instagram (20%).
- Номера и константы взяты из приложения без изменений.
