# Nargiz Shop — prototip

Kosmetika və parfümeriya mağazası üçün demo sayt. «Neçiyədi? Hamısı yazılıb.»

```bash
npm install
npm run dev
```

Next.js 15, TypeScript, Tailwind CSS 4. Backend yoxdur: məhsullar `src/data/products.ts`, səbət brauzerin localStorage-ında. Vercel-ə birbaşa deploy olunur.

Demo plaşkası `src/lib/constants.ts` → `SHOW_DEMO_BANNER` ilə söndürülür. Hesabat: [REPORT.md](REPORT.md).
